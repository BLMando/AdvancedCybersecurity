CSR-Based Enrollment

        
    
          
  • Sicurezza: Keypair generata nel dispositivo del client, mai inviata al server
    • 
          
  • CSR: Solo il Certificate Signing Request viene inviato al server
    • 
          
  • Device binding: MAC e CPU nel certificato (SAN) per Zero-Trust
    • 
          
  • Uniqueness: Non puoi avere due certificati per lo stesso CN
    • 
          
  • X.509v3: BasicConstraints, KeyUsage, ExtendedKeyUsage, SubjectAlternativeName
    • 
          
  • CA persistente: Riutilizzabile per più iscrizioni
    • 
          
  • Metadata: Tracking enrollment_method, timestamp, hardware_info
    • 
        

        

        
Genera CSR localmente

        
python scripts/generate_client_csr.py \
  --cn dr_mario_rossi \
  --department Cardiologia \
  --mac "00:1A:2B:3C:4D:5E" \
  --cpu "Intel(R) Core(TM) i7"
